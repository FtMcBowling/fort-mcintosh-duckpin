One-time setup

Host this HTML app at an HTTPS website. In Google Cloud Console, create a project, enable Google Drive API, configure the OAuth consent screen, and create an OAuth 2.0 Web application client. Add your website origin to Authorized JavaScript origins. Paste the Client ID above, then connect on each tablet.

The app uses the restricted appDataFolder Drive scope: it accesses only its own hidden application files, not your other Drive documents. Google may require OAuth test-user registration or app verification depending on configuration. Do not put a client secret in this HTML file.
